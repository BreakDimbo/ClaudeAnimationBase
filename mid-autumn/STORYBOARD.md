# 《一滴月亮》 STORYBOARD（第二版 · 水彩）

**规格**：180 秒 · 16:9（1920×1080）· 24 fps · 单个自包含 HTML（Canvas 2D + 原生 JS）· 音乐音效与画面同一时间轴

**一句话**：中秋下午，月亮还没画好，只是一滴金色的颜料。它滚过家里每个人的一天，从每个人身上沾走一点颜色，傍晚时分变成一轮圆满的、五颜六色的月亮。

**不讲的故事**：没有人错过火车，没有人等门，没有人哭，也没有一句"想你"。只是十六个人各自忙着，一滴颜料从一个人滚到下一个人。镜头之间不按剧情衔接，而是像走神一样，从一个圆滑到另一个圆：镜片 → 气泡 → 条纹 → 鸟 → 花瓣 → 围巾 → 纽扣 → 格窗 → 蒸汽 → 灯笼 → 闪光灯 → 月亮 → 茶杯 → 一滴。

**爱藏在哪里**：每一镜只藏一个很小的动作，不点破，观众看第二遍才会发现（清单在文末）。

**画风**：
- 人物：直接用人物卡上的彩铅画像抠出的剪纸，像素不改。每人有正面、侧面、背面、3/4 主视图、脸部特写和三种表情（平静、笑、认真）。人物像纸偶一样动：整身平移、轻轻摇晃、呼吸般的起伏、转身时换视图、特写时换表情。
- 世界：湿画法水彩。颜料晕开、边缘积色、层层透叠，留白就是光。每镜一个主色，随全片从清晨的淡蓝灰慢慢走到夜里的靛蓝和金。
- 画面里没有任何文字。

**颜色弧线**：纸白 → 淡蓝（热热）→ 靛蓝（我的河）→ 红白灰（兜兜 / 袋袋）→ 桂花金（桐桐 / 璐璐）→ 桃粉（二姨）→ 暗红（姥姥姥爷）→ 蒸汽白（厨房）→ 黄昏橙紫（路上）→ 夜靛与灯金（圆桌）→ 满月金（全家福）→ 纸白（结尾）。

**母题**：那一滴金色颜料。开头从空白纸上落下，结尾从月亮里落回空白纸上。

**中秋**：故事发生在中秋这一天，从下午到月圆。一只水彩画的小玉兔一路追着金点跑，是串起各镜的小跟班。桂花、月饼模子、柚子、兔子灯、桂花酒、圆桌、赏月、全家福，都是这一天的东西。

**运镜规则**：每一行只用一种运镜（固定 / 横移 pan / 纵移 tilt / 推拉 zoom），不同时做 pan+tilt+zoom。

## 藏起来的爱（不点破，只做动作）
1. 热热：眼镜里有两个月亮，笑了一下，他也不知道在笑什么。
2. 我：一直站在船上，把金点一下一下弹给下一个人。
3. 兜兜：把头靠到袋袋肩上。
4. 桐桐：往璐璐那边挪了半步，替她挡花。
5. 二姨：看一眼手机里的十六个圆点，然后把围巾借给了姥姥。
6. 姥爷：转过脸看着姥姥，没转回来。
7. 爸爸和妈妈：大碗推过去，又推回来。
8. 二舅和二舅妈：背对背，同时往后靠了一点。
9. 热热：走在最后，停下来等人。
10. 茶壶：第一杯斟给姥爷。
11. 我：全家福最后一个跑进画面（拍照的人是我）。
12. 姥姥：结尾端起茶杯的那只手。
