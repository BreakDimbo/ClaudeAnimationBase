# 《日色变得慢》 STORYBOARD（第三版 · 水彩 · 意识流）

**规格**：180 秒 · 16:9（1920×1080）· 24 fps · 单个自包含 HTML（Canvas 2D + 原生 JS）· 音乐音效与画面同一时间轴

> 从前的日色变得慢 / 车，马，邮件都慢 / 一生只够爱一个人 —— 木心《从前慢》

**一句话**：中秋这天清晨，太阳照亮“向阳门第”四个字，门缝里滑出一封信，折成纸鹤，慢慢飞过北京、西安、新加坡、包头、呼和浩特；天黑时太阳已经换成了月亮，门开了，一家人背对着我们一起看月亮。

**意识流**：镜头之间不讲因果，只按形状和颜色走神：朝阳 → 纸鹤 → 鸽哨 → 柿子 → 灯笼 → 钟声的波纹 → 雨 → 水洼里的月亮 → 碎金 → 黄河 → 鹿角间的月 → 蹄印里的花 → 毡房天窗 → 月饼 → 绿皮火车 → 信 → 锁孔里的光 → 夜里的门。

**木心式的浪漫和浅浅的爱**：不说爱，只有很慢、很轻的靠近：两盏灯笼被风吹得碰了一下，又碰一下，就不分开了；纸鹤和兔子灯挨着躲雨；茶杯里的月亮从一只杯子滑进另一只；两缕热气绕在一起；最后，她的头往他肩上偏了一点点。

**人物**：前面全部没有人。只有最后一场（镜 9），全家十六个人的背影站在一起看月亮，按家庭排队：二姨·热热 ｜ 三姨·三姨夫·桐桐 ｜ 大舅·兜兜 ｜ 姥姥·姥爷 ｜ 妈妈·爸爸 ｜ 我·璐璐 ｜ 二舅·二舅妈·袋袋。

**画风**：湿画法水彩，冷压纸纹理。颜料晕开，边缘积色，层层透叠，留白就是光。每座城市一个主色：向阳门第的晨杏色 → 北京秋天的蓝和柿子橙 → 西安夜靛和灯笼红 → 新加坡雨后的薄荷、粉和黄 → 包头的赭黄和钢铁炉火 → 呼和浩特的草原蓝调和寺顶金 → 夜里的靛蓝和月亮金 → 纸白。

**文字**：画面里只有门匾上的“向阳门第”四个字，用程序一笔一笔画出来，不用字体文件。

**运镜规则**：每一行只用一种运镜（固定 / 横移 pan / 纵移 tilt / 推拉 zoom），不同时做 pan+tilt+zoom。
