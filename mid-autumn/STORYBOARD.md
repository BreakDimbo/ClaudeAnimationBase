# 《日色变得慢》 STORYBOARD（第五版 · 120 秒 · 水彩 · 中秋 · 小兔子）

**规格**：120 秒 · 16:9（1920×1080）· 24 fps · 单个自包含 HTML（Canvas 2D + 原生 JS）· 音乐音效与画面同一时间轴

> 从前的日色变得慢 / 车，马，邮件都慢 / 一生只够爱一个人 —— 木心《从前慢》

**明线：中秋这一天，月亮上的小兔子要回家。** 八月十五的清晨，月亮快落下去了，月亮里的玉兔一跃跳下来，落在“向阳门第”的屋脊上，月亮上的兔影从此空了。它跟着门缝里滑出来的一封信（信折成了纸鹤），骑在纸鹤背上走了一整天：北京的白天、包头的日落、呼和浩特的蓝调、西安的夜、新加坡的雨夜。每座城市都有一样中秋的东西：兔儿爷、鹿角间升起的月亮、毡房天窗里的月亮、城墙灯会、南洋的兔子灯。天黑了，它回到向阳门第，门开了，桌上有切好的月饼和茶。一家人站在院子里看月亮，小兔子顺着月光跳回月亮里，月亮上的兔影重新出现。兔子回家，和一家人团圆，是同一件事。

**意识流**：镜头之间不讲因果，按形状和颜色走神：月亮 → 金字 → 信 → 纸鹤 → 鸽群 → 柿子 → 落日 → 黄河 → 鹿角间的月 → 花路 → 毡房 → 天窗 → 红灯笼 → 钟声的波纹 → 雨 → 水洼里的月亮 → 月饼 → 绿皮火车 → 信 → 锁孔里的光 → 夜里的门 → 茶杯里的月亮 → 满月。

**木心式的浪漫和浅浅的爱**：不说爱，只有很慢、很轻的靠近：两盏灯笼被风吹得碰了一下，又碰一下，就不分开了；小兔子挨着兔子灯躲雨；茶杯里的月亮从一只杯子滑进另一只；两缕热气绕在一起；最后，璐璐的头往我肩上偏了一点点。

**人物**：前面没有人，只有小兔子。镜 9 先是全家十六个人的背影站在一起看月亮；小兔子回到月亮后，镜头反打成“月亮看他们”，十六张正脸在月光里一一亮起，最后站成一张全家福。背影按家庭排队：二姨·热热 ｜ 三姨·三姨夫·桐桐 ｜ 大舅·兜兜 ｜ 姥姥·姥爷 ｜ 妈妈·爸爸 ｜ 我·璐璐 ｜ 二舅·二舅妈·袋袋。

**中秋的东西**：满月与玉兔、兔儿爷、柿子与桂花、灯笼与兔子灯、月饼、茶、赏月、团圆。

**画风**：湿画法水彩，冷压纸纹理，留白就是光。城市按一天的时间排：清晨杏色 → 北京白天的蓝 → 包头日落的赭黄 → 呼和浩特的蓝调 → 西安的夜靛与灯笼红 → 新加坡雨夜的薄荷、粉、黄 → 夜里的靛蓝与月亮金 → 纸白。

**文字**：只有门匾上的“向阳门第”四个字（老匾额从右往左读），用程序一笔一笔画出来，不用字体文件。

**剪辑**：120 秒，37 个镜头，全部正常速度。每一次转场都把一个视觉特征带过剪接点，而且 36 次转场用的特征各不相同：动作、云、飞行线、位置、前景遮挡、染色、圆形与颜色、地平线、上升、光、出画入画、云的位置、线、圈入、红色、风向、落叶、涟漪、画中画、轴线推近、视线、倒影、图形匹配、卷轴、甩镜、物件、竖轴、聚光、月光带、门洞、焦点、桂花、斜线、反打、景别、曝白。剪辑表在 src/main.js 的 EDIT，转场效果在 joinPre / joinOver。

**运镜规则**：每一行只用一种运镜（固定 / 横移 pan / 纵移 tilt / 推拉 zoom），不同时做 pan+tilt+zoom。

## 声音（同一时间轴，seeded）
- 一段 8 小节的主旋律（D 宫五声，80 拍/分）贯穿全片，每座城市换一种奏法：清晨古筝独奏；北京笛子配古筝琶音；包头、呼和浩特拉弦乐持续低音（马头琴的颜色），呼和浩特加马蹄般的三连音；西安低音古筝；新加坡高音拨弦；从前慢是火车一样的八分音符；夜里笛子轻吹；团圆时笛子、古筝、和弦一起。小兔子每跳一下有一个轻轻的高音。
- 环境声：鸽哨（北京）、河水与风（包头）、马蹄与草原风（呼和浩特）、钟声（西安）、雨声（新加坡）、火车轮、锁的咔哒声、门轴、桂花落进茶杯、热气。
- 镜 41 日月飞快轮转时用上行琶音；镜 9 兔子回到月亮时各声部合在一起并放慢；镜 10 以一个长音结束。
